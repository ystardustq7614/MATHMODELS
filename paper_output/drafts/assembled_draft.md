# 摘要

中药材热风干燥是中药材产后加工与品质控制的核心工序，其本质是多孔介质内部非线性水分扩散、热传导与烘房边界对流传质传热强烈耦合的非定常物理场演化过程。针对圆柱形药材的干燥动力学与烘干时长预测问题，本文建立了圆柱坐标系下的非定常热湿耦合传热传质偏微分方程（PDE）模型，采用隐式有限体积法（FVM）、Picard非线性迭代、Thomas三对角求解算法以及物质坐标系移动网格方法进行了高精度数值求解与系统机理分析。

针对问题一（预热平衡阶段温湿场演化），建立常热物性但扩散系数随含水率非线性变化的非定常传热传质模型，求解了前 1800 s（30 分钟）内药材径向各截面的温度与干基含水率分布。数值模拟表明：在 1800 s 末，药材中心温度由初始 28.0000°C 升至 33.5766°C，表面温度升至 36.7453°C；表面干基含水率由初始 2.5500 kg/kg 迅速降至 1.5478 kg/kg，而中心含水率仍保持在 2.5500 kg/kg，总脱水率达 0.063924。该结果揭示了由表面对流传质阻力与内部非线性扩散主导的显著内外梯度迟滞效应。空间网格与时间步长收敛性分析显示最大绝对温度偏差分别为 9.310954300190133e-05 K 与 0.0006001100597927689 K，验证了算法的高精度。

针对问题二（全过程统一经验物性模型），采用附录3给出的全过程经验物性公式，全面计入温度与含水率对导热系数、比热容及扩散系数的非线性强化效应，自 t=0 起进行全过程连续求解。结果表明：在 3 h 末，药材中心温度升至 49.8494°C，表面温度达到 49.9646°C，全域迅速贴近烘房温度（约 50.2°C）；中心水分浓度降至 1.7662 kg/kg，表面水分浓度降至 1.0174 kg/kg（在 1800 s 时表面温度为 35.3714°C，表面水分浓度为 1.6719 kg/kg）。相较于分段拼接模型，统一经验物性模型实现了全过程平滑自洽过渡。

针对问题三（固定半径下烘干达标时长判定），严格以药材全域最大含水率低于 0.1500 kg/kg（即最难脱水的轴心位置达标）为终点判据，采用未舍入事件二分夹逼算法，精确测定固定几何尺寸（半径 2 cm）下的烘干时长为 57.3425 小时（即 206433.0 s）。在烘干结束时刻，中心含水率为 0.1500 kg/kg，表面含水率为 0.0666 kg/kg，全域最大含水率达到临界阈值 0.1500 kg/kg，全域最小含水率为 0.0666 kg/kg。远期环境均值延拓灵敏度检验显示相对差异为 0.0%，证明了预测结果的高度鲁棒性。

针对问题四（径向收缩移动边界下的烘干动力学），针对药材失水过程中的径向动态收缩及附录4独立物性组，引入物质坐标变换 $\xi = r/R(t)$ 构建移动网格 FVM 求解器。求解表明：在径向收缩效应作用下，药材烘干所需时间显著缩短至 50.8572 小时（即 183086.0 s），相较固定半径模型耗时缩短了 11.31%。烘干结束时药材半径收缩至 1.200 cm，中心含水率为 0.1500 kg/kg，表面含水率为 0.0605 kg/kg，全域最大含水率达到临界阈值 0.1500 kg/kg，全域最小含水率为 0.0605 kg/kg。移动网格退化校验表明温度与含水率绝对残差分别达到 1.1937117960769683e-12 K 和 2.4424906541753444e-14 kg/kg 量级。几何动态收缩显著缩短了内部水分外排的特征扩散距离，大幅加快了脱水动力学速率。

**关键词**：中药材烘干；热湿耦合；非线性扩散；有限体积法；移动边界；物质坐标变换

# 1 问题重述

## 1.1 研究背景与工程意义
中药材的干燥加工是中药饮片生产及现代化贮藏运输过程中的核心技术环节 [1, 2]。药材内部通常富含植物水分、胶质与活性成分，烘干不仅直接影响中药材的外观色泽、有效成分保留率与耐贮藏性，而且直接关系到加工生产的能耗成本与经济效益。

在工业化热风烘房干燥过程中，湿药材置于具有设定温湿度历程的干燥室内，外部热风通过强迫对流向药材表面传递热量，同时带走药材表面蒸发出的水分 [3, 4]。药材内部则经历复杂的热量传导与水分扩散过程。实验与机理研究表明，中药材多孔介质内部的水分扩散具有强烈的非线性特征，其水分扩散系数通常随含水率的降低而显著减小，在含水率较高阶段水分迁移迅速，而在后期结合水脱除阶段扩散阻力急剧上升 [5]。同时，药材的宏观热物性参数（如比热容、导热系数）在整个烘干周期内亦随温度与含水率发生显著变化。

此外，多数中药材在脱水失水过程中伴随着显著的组织收缩与几何体积变形。随着水分的大量蒸发，药材细胞壁收缩，整体径向尺寸持续减小。这种径向尺寸的动态缩小改变了内部水分向外迁移的特征扩散距离，从而对干燥动力学进程产生深远影响 [7, 8]。因此，建立全面刻画圆柱形中药材在时变烘房环境下的非定常、非线性热湿耦合机理模型，并精准预测烘干达标时长，对于实现中药材干燥过程的智能化精准调控具有重要的工程应用与科学研究价值。

# 2 问题分析


## 2.1 物理机理与系统特性分析
中药材在烘房中的热风干燥过程是一个典型的多孔介质非定常、非线性热质耦合传输系统 [3, 4]。药材置于具有动态温湿度环境的干燥室内，其外部边界受烘房空气对流换热与对流传质驱动，内部则伴随着显热传导与水分浓度梯度驱动的水分扩散。由于药材的长径比为 $L/(2R) = 0.25 / 0.04 = 6.25 > 5$，端部边界的轴向扩散影响在药材中部截面可忽略不计，因此主体传热传质过程可高度近似为圆柱坐标系下的一维径向对称问题。

## 2.2 问题一的机理与求解策略分析
问题一要求分析预热平衡阶段（0-1800 s）内的温度与干基含水率时空演化。在此阶段，药材热物性（密度、比热容、导热系数）取为常数，但水分扩散系数 $D(C) = 7\times 10^{-9}\exp(-0.89/C)\text{ m}^2/\text{s}$ 呈现强烈的非线性指数衰减特征。烘房环境温度与湿度随时间变化，构成非齐次、时变的第三类（Robin）对流换热与传质边界条件。
由于扩散系数随含水率剧烈变化，传统的解析分离变量法失效，必须采用隐式有限体积法（FVM）结合 Picard 非线性迭代与 Thomas 三对角矩阵算法进行求解 [1, 9]。数值计算表明，在 1800 s 末，药材中心温度达到 33.5766 °C（aq1_final_center_temperature_C），表面温度达到 36.7453 °C（aq1_final_surface_temperature_C），升温显著；表面水分浓度降至 1.5478 kg/kg（aq1_final_surface_moisture），而中心水分浓度仍维持在初始 2.55 kg/kg（aq1_final_center_moisture），总脱水率达 0.063924 fraction（aq1_total_moisture_loss_fraction），展现出强烈的内外梯度迟滞特征。算法收敛性测试显示，空间网格加密下最大绝对温度偏差为 9.310954300190133e-05 K（validation_aq1_spatial_T_max_abs），最大水分偏差为 0.0001791344722710253 kg/kg（validation_aq1_spatial_C_max_abs），空间网格检验结果判定为 1 boolean PASS（validation_aq1_spatial_pass）；时间步长加密下最大绝对温度偏差为 0.0006001100597927689 K（validation_aq1_temporal_T_max_abs），最大水分偏差为 4.477288710469374e-05 kg/kg（validation_aq1_temporal_C_max_abs），时间步长检验结果判定为 1 boolean PASS（validation_aq1_temporal_pass）。

## 2.3 问题二的统一经验物性模型分析
问题二旨在建立从 $t=0$ 起连续覆盖预热与干燥全过程的统一经验模型。附录3给出的经验物性关系全面计入了温度与含水率对导热系数、比热容及扩散系数的非线性依赖，避免了人为分段拼接所造成的物性突变与数值震荡。
在连续求解前 3 h（10800 s）后，药材中心温度升至 49.8494 °C（aq2_3h_center_temperature_C），表面温度升至 49.9646 °C（aq2_3h_surface_temperature_C），全域温度已高度趋近于烘房环境温度；中心水分浓度降至 1.7662 kg/kg（aq2_3h_center_moisture），表面水分浓度降至 1.0174 kg/kg（aq2_3h_surface_moisture）。对比显示，在 1800 s 时表面温度为 35.3714 °C（aq2_1800s_surface_temperature_C），表面水分浓度为 1.6719 kg/kg（aq2_1800s_surface_moisture）。统一物性模型表现出优异的数值平滑性与自洽性。

## 2.4 问题三的烘干达标阈值事件判定分析
问题三关注固定几何尺寸（半径 2 cm）下烘干全过程的时长判定。烘干终止的判定准则为药材全域最大含水率低于达标阈值 0.15 kg/kg（aq3_final_max_moisture），由于圆柱内部水分由中心向外径向迁移，水分浓度沿径向单调递减，全域最大含水率恒出现在圆柱中心轴线处（$r=0$）。因此，达标准则等价于中心水分浓度降至 0.15 kg/kg（aq3_final_center_moisture）。
由于干燥过程跨越数十小时，采用长时间步长扫描结合未舍入事件二分夹逼算法，精确确定烘干达标所需时长为 57.3425 h（aq3_drying_time_h），对应 206433 s（aq3_drying_time_s）。烘干结束时刻中心水分浓度达到临界阈值 0.15 kg/kg，表面水分浓度降至 0.0666 kg/kg（aq3_final_surface_moisture 与 aq3_final_min_moisture），全域最小含水率为 0.0666 kg/kg。关于长期环境延拓假设，默认边界外推耗时为 206433 s（validation_aq3_default_threshold_time_s），尾部均值延拓耗时为 206433 s（validation_aq3_tail_mean_threshold_time_s），边界延拓相对差异为 0 fraction（validation_aq3_boundary_relative_difference），边界延拓检验判定为 1 boolean PASS（validation_aq3_boundary_pass）。

## 2.5 问题四的径向收缩移动边界动力学分析
问题四要求计入药材在脱水过程中的径向动态收缩效应与附录4物性组。随着水分蒸发，药材半径由初始 2.0 cm 不断缩小。这一几何尺度的动态缩小使得特征扩散距离减小，显著加速了内部水分向表面的迁移 [7, 8]。
针对移动边界问题，引入物质坐标变换 $\xi = r/R(t)$，将时变物理域映射到固定的无量纲计算域 $0 \le \xi \le 1$ 上，从而准确消除移动网格引起的伪对流数值耗散。求解结果表明，在收缩效应作用下，药材烘干时长缩短至 50.8572 h（aq4_drying_time_h），对应 183086 s（aq4_drying_time_s），相较固定半径模型耗时缩短了 11.31 %（aq4_time_reduction_vs_aq3_percent）。在达标终止时刻，药材半径收缩至 1.2 cm 即 1.200 cm（aq4_final_radius_cm），中心水分浓度达到临界 0.15 kg/kg（aq4_final_center_moisture 与 aq4_final_max_moisture），表面水分浓度降至 0.0605 kg/kg（aq4_final_surface_moisture 与 aq4_final_min_moisture），全域最小含水率为 0.0605 kg/kg。恒定半径移动网格退化校验显示最大绝对温度偏差为 1.1937117960769683e-12 K（validation_aq4_fixed_moving_T_max_abs），最大水分偏差为 2.4424906541753444e-14 kg/kg（validation_aq4_fixed_moving_C_max_abs），退化校验判定为 1 boolean PASS（validation_aq4_fixed_moving_pass）。

# 3 模型假设

为了建立能够精确刻画中药材在烘房环境中热湿迁移机理且在数值上稳定可行的偏微分方程模型，提出以下基本假设 [5, 6]：

## 3.1 模型基本假设
1. **几何对称与一维径向传质假设**：
   药材几何外形视为均匀的长圆柱体，长径比 $L/(2R) = 0.25 / 0.04 = 6.25 > 5$。药材中段横截面的轴向温度与水分浓度梯度远小于径向梯度，因此端部边界效应可忽略不计，主体热湿传输过程严格关于圆柱中心轴对称，退化为一维径向传热传质问题。

2. **固相骨架与干基质量守恒假设**：
   药材由不可压缩的固相干物质骨架与内部液态/气态结合水组成。在整个干燥过程中，干物质的绝对质量保持严格恒定，干燥速率与浓度分布均建立在干基含水率（kg 水/kg 干物质）的基础之上。

3. **宏观等效热物性与显热传导假设**：
   药材内部的热量传递由傅里叶显热传导主导，水分蒸发引起的相变潜热吸收主要发生在药材外表面，内部局部相变潜热效应等效合并至经验给定的宏观等效比热容与导热系数模型之中。

4. **表面对流传热传质 Robin 边界假设**：
   药材表面与烘房气流之间的热湿交换满足牛顿冷却定律与对流传质定律，表面热通量与质通量分别正比于药材表面与烘房环境之间的温差和水分浓度差，对流换热系数 $h$ 与对流传质系数 $h_m$ 为有效宏观参数。

5. **失水收缩的自相似变形假设**：
   在问题四中，药材由于脱水导致的径向收缩在空间上满足自相似均匀收缩特征，即固相骨架各点收缩速度沿径向线性分布 $v_s(r,t) = r \dot{R}(t)/R(t)$，轴向长度变化可忽略。

## 3.2 假设的合理性分析
上述假设充分抓住了多孔介质热风干燥的核心物理矛盾。长圆柱假设在流体与传热工程中属于标准经典处理，显著降低了三维求解复杂度；以干基含水率构建守恒方程避免了湿基质量基准变动引起的非守恒误差；物质坐标系下的自相似收缩假设则保证了移动边界网格变换下的质量守恒与数值几何自洽性。

# 5 模型的建立与求解


## 5.1 预热阶段温度与干基含水率模型的建立与求解 (问题一)

### 5.1.1 建模思路
在预热平衡阶段（0-1800 s），初始冷态中药材置于升温的烘房环境中。烘房热风通过强迫对流向药材表面供热，驱动药材升温；同时表面水分蒸发形成浓度差，驱动内部水分向外扩散 [1, 2]。针对长圆柱体药材，忽略端部轴向耗散，在圆柱坐标系下建立一维非定常径向热传导与非线性水分扩散耦合偏微分方程组。

### 5.1.2 变量定义与公式推导
药材干基质量保持守恒，圆柱半径恒为 $R = 0.02\text{ m}$，长度 $L = 0.25\text{ m}$。控制方程包括温度场与水分浓度场的偏微分方程：

1. **导热微分方程**：
$$
\rho c_p \frac{\partial T}{\partial t} = \frac{1}{r} \frac{\partial}{\partial r} \left( r k \frac{\partial T}{\partial r} \right), \quad 0 < r < R, \ t > 0
$$
其中，$\rho = 820\text{ kg/m}^3$ 为干基等效密度，$c_p = 2600\text{ J/(kg}\cdot\text{K)}$ 为比热容，$k = 0.36\text{ W/(m}\cdot\text{K)}$ 为导热系数。

2. **非线性水分扩散方程**：
$$
\frac{\partial C}{\partial t} = \frac{1}{r} \frac{\partial}{\partial r} \left( r D(C) \frac{\partial C}{\partial r} \right), \quad 0 < r < R, \ t > 0
$$
其中，非线性有效水分扩散系数满足：
$$
D(C) = 7 \times 10^{-9} \exp\left( -\frac{0.89}{C} \right) \quad [\text{m}^2/\text{s}]
$$

3. **定解条件（初始条件与边界条件）**：
- 初始条件（$t = 0$）：
$$
T(r, 0) = T_0 = 28.0000^\circ\text{C} = 301.15\text{ K}, \quad C(r, 0) = C_0 = 2.5500\text{ kg/kg}
$$
- 中心对称边界条件（$r = 0$）：
$$
\left. \frac{\partial T}{\partial r} \right|_{r=0} = 0, \quad \left. \frac{\partial C}{\partial r} \right|_{r=0} = 0
$$
- 外表面 Robin 对流边界条件（$r = R$）：
$$
-k \left. \frac{\partial T}{\partial r} \right|_{r=R} = h \left( T(R, t) - T_{\text{air}}(t) \right)
$$
$$
-D(C) \left. \frac{\partial C}{\partial r} \right|_{r=R} = h_m \left( C(R, t) - C_{\text{air}}(t) \right)
$$
其中，$h = 25\text{ W/(m}^2\cdot\text{K)}$ 为表面对流换热系数，$h_m = 8\times 10^{-7}\text{ m/s}$ 为对流传质系数，$T_{\text{air}}(t)$ 与 $C_{\text{air}}(t)$ 来自附件1环境时间序列。

### 5.1.3 求解算法
算法具体执行步骤如下：
- **Step 1（空间与时间离散）**：采用有限体积法（FVM）对空间圆柱壳层进行离散，将半径区间 $[0, R]$ 等距划分为 $N=80$ 个环状控制容积单元。在时间方向采用一阶全隐式后向欧拉格式（Backward Euler），步长取 $\Delta t = 1.0\text{ s}$。
- **Step 2（Picard非线性迭代与Thomas三对角求解）**：针对非线性扩散系数 $D(C)$，在每个时间步内构造 Picard 迭代方程组 $\mathbf{A}(\mathbf{C}^{(m)})\mathbf{C}^{(m+1)} = \mathbf{b}$。利用 Thomas 算法 [9] 直接消元求解严格对角占优的三对角矩阵。
- **Step 3（收敛判定与状态推进）**：当两次迭代之间的最大差值小于收敛容限 $10^{-10}$ 时判定本步收敛，推进至下一物理时间步。

## 5.2 统一经验物性的全过程模型模型的建立与求解 (问题二)

### 5.2.1 建模思路
在实际烘干全过程中，药材的热导率、比热容及水分扩散系数会随着温度升高和水分蒸发发生显著非线性变化 [3, 4]。附录3给出了全过程统一经验物性表达式，避免了阶段人工拼接造成的截断误差。本节自 $t=0$ 起基于统一物性方程进行全过程连续求解。

### 5.2.2 变量定义与公式推导
在圆柱坐标系下，非线性热湿耦合传热传质控制方程表述为：
$$
\rho(C) c_p(C,T) \frac{\partial T}{\partial t} = \frac{1}{r} \frac{\partial}{\partial r} \left( r k(C,T) \frac{\partial T}{\partial r} \right)
$$
$$
\frac{\partial C}{\partial t} = \frac{1}{r} \frac{\partial}{\partial r} \left( r D(C,T) \frac{\partial C}{\partial r} \right)
$$

### 5.2.3 求解算法

- **Step 2（Picard多场解耦交替迭代求解）**：在每个时间步内，对温度场与水分场交替进行 Picard 迭代推进，调用 Thomas 算法求解代数方程组。
- **Step 3（全过程时间步进与数据导出）**：直至全场相对残差小于 $10^{-7}$，推进至 3 h 结束时刻，并导出 `result2.xlsx`。

## 5.3 固定半径下全域达标时长模型的建立与求解 (问题三)

### 5.3.1 建模思路
中药材烘干加工的终点判定指标通常要求药材整体水分含量达到安全贮藏标准 [5, 10]。根据工艺要求，以药材全域最大含水率低于 0.1500 kg/kg（即最难干燥的圆柱中心位置达标）作为烘干完成准则。本节在固定半径（2 cm）条件下连续推进求解，精准确定达标时长。

### 5.3.2 变量定义与公式推导
烘干达标终止判据定义为阈值事件：
$$
t_{\text{dry}} = \inf \left\{ t > 0 \;\middle|\; \max_{0 \le r \le R} C(r,t) \le C_{\text{threshold}} = 0.1500 \right\}
$$
由于内部水分扩散由中心向表面输运，水分分布沿径向单调递减，最大含水率恒出现在圆柱对称中心轴线处（$r=0$），即判定条件等价于 $C(0, t_{\text{dry}}) \le 0.1500\text{ kg/kg}$。

### 5.3.3 求解算法
算法具体执行步骤如下：
- **Step 1（长周期连续仿真与全域极值监控）**：采用大步长结合状态监测向前推进求解，持续跟踪药材中心含水率。
- **Step 2（达标阈值事件区间锁定）**：当检测到中心含水率首次下穿 0.1500 kg/kg 阈值时，锁定事件发生的秒级时间区间 $[t_k, t_{k+1}]$。
- **Step 3（未舍入事件二分精确夹逼重算）**：在事件区间内进行未舍入事件二分夹逼重算，以 1 秒的高精度精确定位达标临界时刻，并将每隔 6 h 及结束时刻数据导出至 `result3.xlsx`。

## 5.4 收缩域中的烘干时长模型的建立与求解 (问题四)

### 5.4.1 建模思路
药材在脱水过程中细胞收缩导致外径不断减小 [7, 8]。附件2提供了实测的药材半径 $R(t)$ 时间序列，附录4给出了对应的独立经验物性组。随着外径由 2.0 cm 收缩至约 1.2 cm，内部水分外排的几何扩散距离显著缩短。为此，必须建立考虑动态移动边界的传热传质方程。

### 5.4.2 变量定义与公式推导
为处理随时间收缩的物理空间域 $0 \le r \le R(t)$，引入物质坐标系（无量纲坐标变换）：
$$
\xi = \frac{r}{R(t)} \in 无量纲计算域 (0 ≤ ξ ≤ 1)
$$
根据复合函数链式求导法则，空间与时间导数变换关系为：
$$
\left. \frac{\partial}{\partial r} \right|_t = \frac{1}{R(t)} \left. \frac{\partial}{\partial \xi} \right|_t, \quad \left. \frac{\partial}{\partial t} \right|_r = \left. \frac{\partial}{\partial t} \right|_\xi - \frac{\xi \dot{R}(t)}{R(t)} \left. \frac{\partial}{\partial \xi} \right|_t
$$
将水分扩散方程代入变换关系，得到物质坐标系下的守恒型扩散方程：
$$
\frac{\partial (R^2 C)}{\partial t} = \frac{1}{\xi} \frac{\partial}{\partial \xi} \left( \xi D(C,T) \frac{\partial C}{\partial \xi} + \xi^2 R \dot{R} C \right)
$$
式中，附加对流通量项 $\xi^2 R \dot{R} C$ 严格反映了因网格收缩引起的物质迁移对流速度。

### 5.4.3 求解算法
算法具体执行步骤如下：
- **Step 1（物质坐标系映射与移动几何速度计算）**：在固定无量纲计算域 $\xi \in 无量纲计算域 (0 ≤ ξ ≤ 1)$ 上划分离散控制容积，利用样条插值计算实测半径 $R(t)$ 及其收缩速度 $\dot{R}(t)$。
- **Step 2（守恒型对流-扩散离散方程组组装）**：对附加对流通量项采用逆风/中心混合格式，结合附录4经验物性组装隐式三对角矩阵系统。
- **Step 3（Picard迭代与达标终点夹逼确定）**：执行非线性 Picard 迭代，利用二分重算法精确锁定中心含水率达到 0.1500 kg/kg 阈值的时刻，数据导出至 `result4.xlsx`。

## 附录 A：主要求解代码实现说明与核心算法片段
为了保证本文所建数学模型与数值计算结果的完全可复现性，本附录给出了求解圆柱坐标系下非定常热湿耦合偏微分方程的核心算法实现。求解器基于一维有限体积法（FVM）构建，结合了非线性 Picard 逐次代换迭代与高效的 Thomas 三对角矩阵直接消元算法。通过在每个时间步内对导热与扩散系数进行动态重构与调和平均插值，确保了界面热通量与质通量的严格连续与全局守恒。

```python
# 核心三对角求解算法与 Picard 非线性迭代框架
import numpy as np

def solve_fvm_tridiagonal(A_lower, A_diag, A_upper, b):
    """Thomas 算法求解三对角线性方程组"""
    n = len(b)
    c_prime = np.zeros(n - 1)
    d_prime = np.zeros(n)
    c_prime[0] = A_upper[0] / A_diag[0]
    d_prime[0] = b[0] / A_diag[0]
    for i in range(1, n - 1):
        denom = A_diag[i] - A_lower[i - 1] * c_prime[i - 1]
        c_prime[i] = A_upper[i] / denom
        d_prime[i] = (b[i] - A_lower[i - 1] * d_prime[i - 1]) / denom
    denom = A_diag[n - 1] - A_lower[n - 2] * c_prime[n - 2]
    d_prime[n - 1] = (b[n - 1] - A_lower[n - 2] * d_prime[n - 2]) / denom
    x = np.zeros(n)
    x[n - 1] = d_prime[n - 1]
    for i in range(n - 2, -1, -1):
        x[i] = d_prime[i] - c_prime[i] * x[i + 1]
    return x
```
