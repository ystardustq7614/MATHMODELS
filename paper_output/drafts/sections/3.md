# 3 模型假设

为了建立能够精确刻画中药材在烘房环境中热湿迁移机理且在数值上稳定可行的偏微分方程模型，提出以下基本假设 [5, 6]：

## 3.1 模型基本假设
1. **几何对称与一维径向传质假设**：
   药材几何外形视为均匀的长圆柱体，长径比 $L/(2R) = 0.25 / 0.04 = 6.25 > 5$。药材中段横截面的轴向温度与水分浓度梯度远小于径向梯度，因此端部边界效应可忽略不计，主体热湿传输过程严格关于圆柱中心轴对称，退化为一维径向传热传质问题。

2. **固相骨架与干基质量守恒假设**：
   药材由不可压缩的固相干物质骨架与内部液态/气态结合水组成。在整个干燥过程中，干物质的绝对质量保持严格恒定，干燥速率与浓度分布均建立在干基含水率（kg 水/kg 干物质）的基础之上。

3. **宏观等效热物性与显热传导假设**：
   药材内部的热量传递由傅里叶显热传导主导，水分蒸发引起的相变潜热吸收主要发生在药材外表面，内部局部相变潜热效应等效合并至经验给定的宏观等效比热容与导热系数模型之中。

4. **表面对流传热传质 Robin 边界假设**：
   药材表面与烘房气流之间的热湿交换满足牛顿冷却定律与对流传质定律，表面热通量与质通量分别正比于药材表面与烘房环境之间的温差和水分浓度差，对流换热系数 $h$ 与对流传质系数 $h_m$ 为有效宏观参数。

5. **失水收缩的自相似变形假设**：
   在问题四中，药材由于脱水导致的径向收缩在空间上满足自相似均匀收缩特征，即固相骨架各点收缩速度沿径向线性分布 $v_s(r,t) = r \dot{R}(t)/R(t)$，轴向长度变化可忽略。

## 3.2 假设的合理性分析
上述假设充分抓住了多孔介质热风干燥的核心物理矛盾。长圆柱假设在流体与传热工程中属于标准经典处理，显著降低了三维求解复杂度；以干基含水率构建守恒方程避免了湿基质量基准变动引起的非守恒误差；物质坐标系下的自相似收缩假设则保证了移动边界网格变换下的质量守恒与数值几何自洽性。
