# A题 S2 模型、验证与交接决定

2026-09-10。依据A题四页题面、两份官方数据、四份输出模板及用户约束制定。本文件替代旧选题比较和计划审阅草案。S2是已确定的计算路线，不是运行结果或经实证验证的结论。

## 1. 状态变量与最小闭合

长度L=0.25 m，初始半径R0=0.02 m，初始T=301.15 K，C=2.55 kg/kg干物质。内部全用SI单位，显示温度转为°C。模型代表远离端面的径向截面；不将此近似宣称为整个有限圆柱的精确三维解。

采用随固体运动的有效扩散模型。定义物质导数 Dt=∂t+v∂r，径向算子 L_a(u)=(1/r)∂r(r a ∂r u)：

    Dt C = L_D(C)
    rho_th(C) cp(C) Dt T = L_k(T)

Q1—Q3中v=0、R=R0。Q4中长度不变、自相似径向收缩，v=r R'(t)/R(t)，R(t)由附件2驱动。Q1热物性固定，但D(C)不固定；Q2/Q3从同一原始初值全程采用附录3；Q4全程采用附录4。Q2不拼接Q1末态。

该最低闭合忽略机械功、轴向传输及显式蒸发潜热，以温度相关扩散和含水率相关热物性形成耦合。题面未提供材料吸附等温线和汽化位置，不能从现有输入唯一恢复更完整热湿模型。简化须保留在结论适用范围中，不宣称已建立完整热力学守恒模型。

### 1.1 边界与物理含义

中心C_r=T_r=0；表面采用

    -D C_r = hm (Cs-Ce(t))
    -k T_r = h (Ts-Tair(t))

h=25 W/(m² K)，hm=8e-7 m/s，Q2—Q4继承题给换热/传质系数。Ce取附件1的kg/kg字段作为有效边界参考浓度，是无新增参数的工程假设，不是从气相湿含量推导出的真实材料平衡含水率；其相同书写单位不证明两相质量基准相同。不得称Ce为相对湿度。环境升温或回湿时保留通量符号，不裁剪负通量。

稳态边界参考值约0.05、阈值0.15，二者不同；干燥终点由全域最大C判定。S5对Ce±20%及hm×{0.5,1,2}做敏感性，不能用这一检验冒充吸附关系的验证。

### 1.2 收缩坐标与水分收支

令xi=r/R(t)、c(xi,t)=C(r,t)，由于网格速度等于上述固体速度，Dt C=∂t c|xi，得到

    c_t = 1/(R² xi) ∂xi(xi D c_xi)
    rho_th cp theta_t = 1/(R² xi) ∂xi(xi k theta_xi)
    -D/R c_xi(1) = hm (cs-Ce)
    -k/R theta_xi(1) = h (thetas-Tair)

在本物质坐标假设下不再额外添加R'/R平流项；若改用静止固体的Euler模型则方程不同，不能混写。零驱动均匀C在任意R(t)下应保持常数，这是必要退化检验。

取均匀参考干物质密度rho_d0，运动域中rho_d(t)=rho_d0(R0/R)²，满足固体连续性。水质量与流出通量为

    M_w = 2 pi L rho_d R² ∫_0^1 c xi dxi
    J_out = 2 pi R L rho_d hm (cs-Ce)
    dM_w/dt = -J_out

因此无须估计rho_d0即可检验按干物质量归一的守恒：Cbar=2∫c xi dxi，dCbar/dt=-(2hm/R)(cs-Ce)。此式在固定域同样成立。后续报告优先使用该归一水分收支，不输出缺少干物质量依据的绝对失水kg。

**密度解释限制：** 题给rho(C)在本闭合中用于经验热容量rho_th cp；不同时要求它等于rho_d(t)(1+C)。固定几何、已给R(t)、均匀自相似运动与局部湿体密度经验式通常不能全部独立满足。不得把上述条件性水分守恒解释为经验湿体密度的一致验证。S5另记录二者比例的空间变化作为模型局限诊断；若有独立干物质量/体密度数据，必须重新审核本闭合。

热方程验证使用其离散储能项与净热通量的残差。rho_th cp随C变化时，不能把∫rho_th cp T dV的变化直接等同于热通量积分；那会漏掉物性变化项。完整焓和潜热守恒留作有独立参数支持后的升级，当前不宣称通过该验证。

## 2. 输入插值与长期外推

- 附件1：0—14400 s保留原始观测波动，温度与Ce分别线性插值；4 h后保持末点50.165°C、0.04986 kg/kg。主结果明确依赖此恒温恒湿延拓假设。

## 3. 离散与求解要求（S4尚未编写）

径向环形有限体积，后向欧拉，Picard冻结每轮物性并耦合更新温度和C，Thomas算法解三对角系统。面系数采用基于半单元阻力的调和平均；表面半单元扩散阻力与对流阻力串联，并从通量反求真实表面值。中心控制体用积分，不计算1/0。

物质坐标控制体的干物质权重固定；热方程使用当前几何的体积/面积和rho_th cp。禁止把控制体当前水量简单乘R²后又添加额外收缩失水项。导出中心、表面及物理坐标时使用与边界条件一致的重构。

建议起始N=80个径向单元、dt=1 s；这只是待检验计算设置，不是已证实足够精细。Picard相邻迭代变化阈值T≤1e-7 K、C≤1e-10 kg/kg，同时检查离散残差；最多50轮，失败则该步减半，记录重试。细分时间步服务于稳定和收敛，输出仍按规定整数秒。

AQ3/AQ4记录max C-0.15的变号区间，区间内二分重算至宽度≤1 s；同时记录严格达标的右端状态，显示小时四位小数但保留内部未舍入秒数。3天不是强制终点：先算72 h，若未达标可延至7天并披露两项外推；7天仍未达标则报告未达标，不捏造时长。
