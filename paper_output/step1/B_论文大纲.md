# 候选论文结构

三题均可使用同一主结构：摘要、问题重述、假设与符号、数据与预处理、四个子问、检验与敏感性、模型评价、结论、参考文献、附录。

## A 题重点章节

1. 一维轴对称热湿耦合方程与边界条件
2. 有限体积离散及非线性求解
3. 烘干终止事件
4. 收缩坐标变换和固定边界对照

## B 题重点章节

1. 示向误差角扇区与凸定位区域
2. 鲁棒第二检测点设计
3. 全向源覆盖搜索与主动交会
4. 定向源多方位搜索、模拟器实验和日志统计

## C 题重点章节

1. 储能状态方程与确定性日前优化
2. 负荷/光伏预测及无信息泄漏回测
3. 多时点预报更新与滚动优化
4. 波动电价情景、成本分解和策略对照

选题确定后，只保留所选题目的结构并扩展为正式大纲。
